# research

Proyecto de tesis: clasificación de requerimientos no funcionales (NFR) con aumentación
de datos (TAOS, EDA, SMOTE-Tomek), BERT y LLMs como clasificadores.

## Autores
- Alessandro Pastor Mamani Mamani
- Andres Lino Montes Mamani
- Cristian Cabana Sulca

**Asesor:** Mg. Esteban Tocto Cano — Escuela Profesional de Ingeniería de Sistemas, Universidad Peruana Unión.

## Estructura
- `RSL/` — Revisión sistemática de literatura (LaTeX, PDF y `referencias_nfr.bib`).
- `EstadoArte/` — Estado del arte en formato IEEE (LaTeX y PDF).
- `recursos/` — Imágenes usadas por los documentos.
- `Articulos/` — Material de búsqueda bibliográfica.
- `PPI/`, `ShowPaper/` — En desarrollo.
